## 可安全採用的證據

- **作者確實以此主題公開發表內容（高確定性）。** Greg Isenberg 的官方網站將其定位為 Late Checkout CEO，並列出 AI content automation、Agents Skill Suite 等相關資源；這支持「這是作者的工作框架／倡議」，不支持職位需求或薪資預測。[Greg Isenberg 官方網站](https://www.gregisenberg.com/)
- **「marketing engineer」的定義屬作者提出的角色模型（中確定性）。** 可取得的節目逐字稿將角色描述為：用 AI agents、資料、程式碼與品味，把市場訊號轉成 pipeline；並以 Growth OS、customer truth、founder content、outbound、creative testing 與 eval loop 為組成部分。[節目逐字稿鏡像（Podscan）](https://www.podscan.fm/podcasts/the-startup-ideas-podcast-2/episodes/making-as-a-marketing-engineer)（逐字稿並非作者自有出版頁，故只作內容交叉核對。）
- **「把資料集中到 repo／結構化資料夾」是可實作的工作方式，不是已證成的成效定律（高確定性）。** Git 官方文件確認 repository 可追蹤檔案版本與分支；這支持 Growth OS 需要可持續、可追蹤的外部記憶，但沒有證明它必然帶來更多 pipeline。[Git `git-repository` 文件](https://git-scm.com/docs/gitrepository-layout)
- **「agent 能寫程式或操作工作流」要依產品和權限設定理解（高確定性）。** Claude Code 官方文件將其描述為可讀取 codebase、編輯檔案及執行命令的 coding tool；OpenAI 的 Codex 文件則將其描述為能讀、修改與執行程式碼的 coding agent。這只能核對能力存在，不能核對貼文所列工具的相對速度、成本或品質。[Claude Code overview](https://docs.anthropic.com/en/docs/claude-code/overview)、[OpenAI Codex](https://openai.com/codex/)
- **「agent workflow 需要外部治理」有一手依據（高確定性）。** Anthropic 的 agent engineering 文章把長任務的進度、狀態與驗證視為 harness 設計的一部分；OpenAI 的安全說明則將 sandbox 與 approval policy 作為模型外的控制。這支持在 Growth OS 實驗中保留權限、審核、測試與可追蹤紀錄，不支持無人監督地自動發信、改價或部署。[Anthropic：Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)、[OpenAI：Running Codex safely](https://openai.com/index/running-codex-safely/)
- **「薪資可達 25 萬／50 萬／100 萬美元」無法由可得一手資料驗證（高確定性）。** 這是節目／貼文作者的預測；未找到職缺統計、薪資調查、樣本、定義或方法，文章不可寫成市場行情。
- **「公司已有分散的 CRM、通話、內容和產品訊號」是合理觀察但未量化（中確定性）。** 逐字稿以作者自身經驗敘述；沒有公開資料證明普遍企業都如此，也沒有因果證據證明集中後必然提升轉換率或學習速度。
