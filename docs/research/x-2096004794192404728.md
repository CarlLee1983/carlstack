## 可安全轉述的主張

原貼文的主張是：這份手冊要從 Q/K/V 公式連到現代 LLM 中的實際執行，並以手算示例與原始論文引文輔助理解。這可作為本文的選題來源；不把貼文的瀏覽、按讚、收藏或轉貼數寫成技術證據。

## 一手來源對照

| 可安全主張                                                                                      | 來源與確定性                                                                                                                     | 寫作限制                                                                 |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Scaled dot-product attention 以 query 對 key 打分、縮放、softmax 後加權 value。                 | [Attention Is All You Need](https://arxiv.org/abs/1706.03762)，高確定性。                                                        | 以 shape 與矩陣乘法說明，不把權重當成因果解釋。                          |
| RoPE 將位置以旋轉納入 attention 的 Q/K 表示，並表達相對位置關係。                               | [RoFormer](https://arxiv.org/abs/2104.09864)，高確定性。                                                                         | 不泛化為任意模型都可任意延長 context。                                   |
| FlashAttention 是 exact attention 的 IO-aware 演算法，以 tiling 減少 HBM 與 SRAM 間資料讀寫。   | [FlashAttention](https://arxiv.org/abs/2205.14135)，高確定性。                                                                   | 不把特定論文 benchmark 當成任意硬體的加速承諾。                          |
| PyTorch SDPA 會依 inputs 選擇可用實作；其 boolean `attn_mask=True` 表示該位置可參與 attention。 | [PyTorch SDPA docs](https://docs.pytorch.org/docs/stable/generated/torch.nn.functional.scaled_dot_product_attention)，高確定性。 | 明確提醒它與 `MultiheadAttention.key_padding_mask` 的 boolean 語意相反。 |
