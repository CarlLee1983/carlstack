## 原文與採用邊界

原文是長篇入門與帳號安全指南，涵蓋 Claude 網頁版／Claude Code／Console API、訂閱與額度、代理與 DNS、個人帳號停用經驗及申訴。本文採用其「不要把個案當成風控規則」與「先分類錯誤」觀點，縮成工程師可操作的五類排查順序。不轉述第三方 VPN 價格、住宅 IP 評分、設備指紋或封號機率；這些並無可核對的官方因果證據。

## 一手資料核對

- [Pro／Max 與 Claude Code](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)：訂閱使用額度共用、`/status`、達上限後的選項，以及 `ANTHROPIC_API_KEY` 可能使 Claude Code 走 API 計費。
- [Claude Code 指令](https://code.claude.com/docs/en/commands)：`/usage` 顯示方案額度，`/status` 顯示帳號、模型與連線狀態。
- [管理 API key 環境變數](https://support.claude.com/en/articles/12304248-manage-api-key-environment-variables-in-claude-code)：API key 優先於訂閱登入；要使用訂閱額度，需處理變數設定來源。
- [訂閱與 API 分開計費](https://support.claude.com/en/articles/9876003-i-have-a-paid-claude-subscription-pro-max-team-or-enterprise-plans-why-do-i-have-to-pay-separately-to-use-the-claude-api-and-console)：個人訂閱不包含 Console API 使用量。
- [Claude Code 網路設定](https://code.claude.com/docs/en/network-config)：`HTTPS_PROXY`、`HTTP_PROXY`、`NO_PROXY` 支援；不支援 SOCKS；環境變數於啟動時讀取。此文件已更新，舊版文件對 `NO_PROXY` 的描述可能不同，發文以目前頁面為準。
- [安全措施與申訴](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)：官方列出的停用原因、登入受限帳號後申訴、組織暫停審查與資料匯出。
- [支援地區](https://www.anthropic.com/supported-countries)：Claude.ai 與 API 分別列出地區；名單可能變動。
- [Claude 服務狀態](https://status.claude.com/)與[錯誤排查](https://support.claude.com/en/articles/12466728-troubleshoot-claude-error-messages)：一般登入或服務錯誤先排除供應商事故；此為五類本地／帳號排查前的檢查。

## 寫作判斷

五類是本文的排查模型，不是 Anthropic 官方錯誤分類或停用演算法。先保存可驗證訊號，再到各服務的權威頁面確認；本機網路與登入修復不等於解除伺服器停用。避免要求讀者印出憑據或完整代理設定。
