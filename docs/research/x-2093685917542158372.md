# X 貼文研究筆記：把 Claude 設定成工作環境前，先建立權限與驗收順序

> 研究日期：2026-09-08（Asia/Taipei）
> 原文：[Yarchi／X status 2093685917542158372](https://x.com/undefinedKi/status/2093685917542158372)

## 原文可核對內容

Yarchi 的 X Article 主張可透過 memory、projects、skills、connectors、scheduled tasks、文件產物與瀏覽器功能，減少每次重新交代 context 的時間。這是作者的操作指南，不是 Anthropic 的完整官方規格。

原文宣稱「Twelve steps」，但頁面可見的小節只有 1 到 11，接著直接進入〈The order is the point〉；第 12 步未出現。文章不可把「十二步」當成可驗證事實。

## 一手來源對照

| 能力            | 官方可驗證範圍                                                                                                                                                                                                       | 寫作限制                                |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Memory          | 可搜尋舊對話、在新 chat 與 Cowork 帶入記憶；可檢視、編輯、關閉與更新。 [Anthropic Help](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context)            | 記憶不等於資料仍正確或適合每一個任務。  |
| Projects        | Cowork project 有獨立 instructions、tasks、context 與 memory；memory 不跨 project。 [Anthropic Help，2026-04-09](https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-claude-cowork) | 不應把所有工作塞進同一 project。        |
| Skills          | 可自動套用到對應工作；官方範例涵蓋 Office add-ins。 [Anthropic Help](https://support.claude.com/en/articles/12512180-use-skills-in-claude)                                                                           | 先從重複且已驗證的方法萃取。            |
| Connectors      | 繼承使用者在外部服務的權限，可讀資料，也可能採取行動。 [Anthropic Help](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)                                              | 不支持「一次連接全部」；按 scope 核准。 |

| Chrome          | 能讀取、點擊、輸入與導覽網站；官方要求審核 agent action。 [Anthropic Help](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)                                                        | 高副作用行為保留人類核准。              |
| Excel           | 支援公式關係、multi-tab 與 cell-level citations；不應未審核用於對客最終交付或 audit-critical calculation。 [Anthropic Docs](https://claude.com/docs/office-agents/excel)                                             | 檔案輸出必須由人檢查。                  |

## 可安全採用的結論

1. 先建立 project 邊界與可更正的 memory，再把兩次以上驗證過的流程寫成 skill。
2. connector、schedule、browser 與檔案寫入依副作用遞增採用；它們不是「setup 完整度」指標。
3. 每一層先留一個可讀回的驗收點；找不到權威結果時，回報 unknown，不用模型推測成功。
