# OpenRouter 推論供應商資料處理｜2026-11-23

- [OpenRouter 公告](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/) 11/22：三家供應商移出、125 個端點取消 ZDR 資格含預防性移除、通知潛在受影響帳戶。研究未顯示閘道本身遭入侵。未將受影響供應商公告清單與被移出名單畫等號。
- [Novita 公告](https://novita.ai/blog/minimax-requests-privacy-notice/) 11/22：5/28–11/11 部分 MiniMax 請求轉送；直連及 OpenRouter 路徑，可存取或留存，不宣稱所有請求外洩。留存與刪除仍待確認。
- [Together AI 公告](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026) 11/21：6、7 月部分 prompt 樣本確實因另一條憑證曝露路徑遭下載。不嘗試重現，不把個別供應商路徑混用。
- [ZDR 文件](https://openrouter.ai/docs/guides/features/zdr) 與 [Provider Routing](https://openrouter.ai/docs/guides/routing/provider-selection) 11/23 讀取：每次請求和帳戶／guardrail 可限制路由；Safety Retention 可例外、推論與工具不同、官方將某些記憶體快取列為合格。用 only 白名單與 order 偏好區分。
- 正文的客服、失敗替身、合法備援和審計欄位是工程建議，未送實際模型請求或測對外服務。不收集真正憑證，不描述攻擊重現。
