## 原文主張與可用邊界

原文將 KV cache 手法按減少的項目拆開：KV heads（GQA／MQA）、獨立 layer cache（CLA）、保留 token（sliding window／eviction）、儲存表示寬度（MLA）、每個值的 bytes（quantization）、會成長的 state（hybrid recurrent layer），以及 allocation／重複資料（paging／prefix reuse）。另強調 sparse attention 可能只減少讀取量，未必釋放 GPU 容量。

可安全轉述為作者的 serving 分類框架；不可把單一模型或論文的記憶體／吞吐數字套到其他 checkpoint、context、batch、硬體或 engine。
