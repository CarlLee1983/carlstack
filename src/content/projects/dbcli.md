面向 AI Agent 的統一資料庫 CLI，讓 Claude Code、Gemini、Copilot 與 Cursor 等工具透過同一介面探索、查詢及操作資料庫。權限控管、敏感資料保護與命令黑名單放在 CLI 邊界執行，避免每個 Agent 各自處理資料存取風險。
